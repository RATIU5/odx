Comments and string literals are not foreign declarations. This rule does not
follow imports or identify foreign behavior at runtime.

```odin fires
foreign import libc "system:c"
foreign libc {
	getchar :: proc() -> i32 ---
}
```

```odin silent
Status :: enum { Ready, End }
Read :: proc() -> Status { return .Ready }
Foreign_Note :: "foreign import libc"
```
