---
id: R4
class: dependencies_foreign_placement
statement: foreign imports and foreign blocks live only in edge packages.
why: The FFI boundary is where the ABI and calling convention change; keep it in one place. This is a mechanical justification, not a taxonomic one.
severity: error
instead_of: Foreign blocks wherever the binding is first needed.
evidence: A foreign block changes the ABI and calling convention at that point; scattered blocks mean scattered unsafety.
cost: A dedicated edge package per native dependency.
blocking: true
role: pure
check: { kind: banned_construct, construct: foreign_decl, except_roles: ["edge"] }
---

```odin fires
#+vet explicit-allocators
foreign import libc "system:c"

@(default_calling_convention = "c")
foreign libc {
	abs :: proc(x: i32) -> i32 ---
}

magnitude :: proc(x: i32) -> i32 {
	return abs(x)
}
```

```odin silent
#+vet explicit-allocators
magnitude :: proc(x: i32) -> i32 {
	return x if x >= 0 else -x
}
```
