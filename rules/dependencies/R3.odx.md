---
id: R3
class: dependencies_hidden_state
statement: No mutable package-level variables in pure or service packages; pass state as a parameter.
why: "'Globals and/or thread local variables... are just dreadful solutions.' Hidden state makes two calls with the same arguments give different answers. Edge packages own the process and are the one place a global may live."
severity: error
instead_of: Package-level state read and written from several procedures.
evidence: "'Globals and/or thread local variables... are just dreadful solutions'; two calls with the same arguments give different answers."
cost: State becomes a parameter or a struct the caller owns; edge packages are exempt.
blocking: true
role: pure
check: { kind: banned_construct, construct: mutable_global, roles: ["pure", "service"] }
---

```odin fires
#+vet explicit-allocators
count: int

bump :: proc() -> int {
	count += 1
	return count
}
```

#+vet explicit-allocators
Counter :: struct {
