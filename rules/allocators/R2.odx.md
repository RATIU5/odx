---
id: R2
class: allocators_owner_parameter
statement: A procedure that allocates takes `allocator := context.allocator` as its last parameter and documents who frees.
why: Callers pick arenas or trackers ('a good API offers a way to specify the allocator to use'); the doc comment says who frees because a signature cannot. Inside a tagged file the default is unreachable from other tagged files, so it serves untagged callers; R1 and R2 do not conflict.
severity: error
instead_of: Allocating internally with whatever context.allocator holds and documenting nothing.
evidence: "'A good API offers a way to specify the allocator to use'; callers using arenas or tracking allocators in tests cannot otherwise reach the allocation."
cost: One extra parameter on every allocating procedure, and a doc comment the tool can only check for existence.
blocking: false
check: { kind: example }
---

```odin fires
words :: proc(s: string) -> []string {
	out := make([dynamic]string)
	append(&out, s)
	return out[:]
}
```

```odin silent
// Caller owns the result; free with delete(result, allocator).
words :: proc(s: string, allocator := context.allocator) -> []string {
	out := make([dynamic]string, allocator)
	append(&out, s)
	return out[:]
}
```
