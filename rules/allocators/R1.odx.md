The tag is the whole rule: with it, the compiler is the enforcer.

```odin fires
double :: proc(x: int) -> int {
	return x * 2
}
```

```odin silent
#+vet explicit-allocators
double :: proc(x: int) -> int {
	return x * 2
}
```
