why: "Only the attribute makes the compiler reject a discarded failure; -vet does not (`x, _ := f()` and a bare `g()` both pass). This is odx's convention, not a documented Odin one.",

check: { kind: "require_attribute", attribute: "require_results", on: "exported_procs" },

Without the attribute a bare call compiles and the failure vanishes.

```odin prelude
Error :: enum {
	None,
	Not_Found,
}
```

```odin fires
read :: proc(path: string) -> (data: []byte, err: Error) {
	return nil, .Not_Found if len(path) == 0 else .None
}
```

```odin silent
@(require_results)
read :: proc(path: string) -> (data: []byte, err: Error) {
	return nil, .Not_Found if len(path) == 0 else .None
}
```
