Classification matches `errors.types` suffixes against the compiler's canonical named final
result type. Aliases use the underlying name; distinct types retain their own name. By default,
`errors.structural: true` also selects named enums with `None` or `Ok` and named nil-able
unions. These are project heuristics: optional values and status enums can match too.
Set `errors.structural: false` for suffix-only matching; an empty `types` list then selects
nothing. Anonymous result types, private procedures, and non-final errors are outside this
rule. There is no proof that callers inspect failures or recover correctly.

Without the attribute a bare call compiles; with it callers can still explicitly discard results.

```odin prelude
Error :: enum {
	None,
	Not_Found,
}
```

```odin fires
read :: proc(path: string) -> (data: []byte, err: Error) {
	return nil, .Not_Found if len(path) == 0 else .None
}
```

```odin silent
@(require_results)
read :: proc(path: string) -> (data: []byte, err: Error) {
	return nil, .Not_Found if len(path) == 0 else .None
}
```
