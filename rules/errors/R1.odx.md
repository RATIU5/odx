---
id: R1
class: errors_typed_result
statement: Exported procedures that can fail return an error type as the last result, not a bool.
why: A bool, and equally a single universal error type, is 'all the same degenerate value: error or not... a fancy boolean'. Callers cannot branch on it or report it.
severity: error
instead_of: Returning (T, bool) or an ok flag from a procedure with more than one failure mode.
evidence: "'All the same degenerate value: error or not... a fancy boolean' (Exceptions, 2018); callers cannot branch on or report a bool."
cost: An Error type per package to declare and keep exhaustive.
blocking: false
check: { kind: example }
---

A bool says that something failed, never what.

```odin fires
open :: proc(path: string) -> (handle: int, ok: bool) {
	return 0, len(path) > 0
}
```

```odin silent
Error :: enum {
	None,
	Not_Found,
	Permission,
}

@(require_results)
open :: proc(path: string) -> (handle: int, err: Error) {
	return 0, .Not_Found if len(path) == 0 else .None
}
```
